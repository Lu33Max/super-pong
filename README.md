# SuperPong

## The project

This project was created as part of my Media Informatics studies at the University of Applied Sciences Mittweida during the "Applied Game Development" module. Students were tasked with creating small game experience over the span of a single semester within either Unity or Unreal Engine. In an additional report, further insides into the development process should be given, explaining the core mechanics and gameplay loop, describing the projects software architecture and talking about especially challenging parts of development and how they were overcome.

## The game

The original Pong game is now over 50 years old and has remained ingrained in people's minds through its simple concept up to the present day. The goal was to revive this design ideology by adding some simple enhancements to bring the game concept into the modern era. Thus, Super Pong was born, which challenges players not only in their reaction time but also with its strategic components. Collect different balls during a match and try to knock out your opponent through tactical deployment. Each ball comes with its own unique behavior pattern and values, providing the right solution for every situation.

## Installation

1. Download the project files from GitHub
2. Open Unity Hub. Select Add > Add from disk
3. Make sure Unity version 2021.3.21 is installed
4. Open the project within the Unity engine. From here you can play inside the editor or build the game
